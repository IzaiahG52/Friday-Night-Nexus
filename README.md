# Friday Night Nexus

A mod for **Friday Night Funkin'** (2021) that repaints most of the weeks and adds custom dialogue, with my friends added to the game as characters, voiced by them.

## Features

- Moderate visual repaint across most of the weeks
- Custom dialogue throughout
- Friends added into the game with their own voices
